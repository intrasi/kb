From the checklist on Khosla's talk:
- Draft the headlines in a plain text file before designing any slide.
- Each headline is a statement ("Team engineered for this specific opportunity"), never
  a category ("Team").
- One message per slide.

For Garaža's 3 minutes ([[garaza-pitch-three-minutes-one-minute-demo]]) that means about
6 to 8 headlines, not 20. Agent use: before building the deck, generate the headline file,
read it top to bottom, and check that it alone makes the case.

Confidence is moderate because the source is a secondhand summary of the talk.
