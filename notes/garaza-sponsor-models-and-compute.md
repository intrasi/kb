What the Tech Credits page offers (redemption steps and codes are on the Notion page):

| Sponsor | What we get | Limits |
| --- | --- | --- |
| Codeplain (via Turri) | Short-term AWS Bedrock keys (OpenAI and Anthropic models) and Google Gemini keys | Hackathon only; set up turri.dev, then ask Codeplain with the team name. 300 Codeplain credits after the event, valid 30 days |
| Platinum | $100 of compute: "small, powerful computers" for AI agents | New users only, compute only, valid 7 days; claim at the venue |
| Perplexity | $25 across Search, Embeddings, Decisions, and Agent APIs | Account on the email used to apply; Agent API needs a card on file |
| Kortix | Free credits | Redeem before the event ends |
| Lovable | Pro Plan 1 (100 credits) | Redeem by the end of the event |
| ElevenLabs | 1 month of Creator tier | Via their Discord bot |

Why it matters to us: the attacker simulation (an LLM plus a decompiler trying to recover
logic) burns tokens on every run, so the Bedrock and Gemini keys pay for the benchmark,
and running it across vendors (Anthropic, OpenAI, Gemini) makes the attacker-cost number
more credible. Platinum boxes can host the decompiler and solver runs. Perplexity's
Search API can feed the market-research agents. Keys must never be committed.
