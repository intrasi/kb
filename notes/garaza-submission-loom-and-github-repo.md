The guidebook asks each team to email a Loom video link (the product demo) and a GitHub
repo to the organisers before 4pm on Sunday, subject "{Team Name} Hackathon Submission".

Why it matters to us: the code repo is a deliverable that judges can open, so it needs a
README that runs the demo end to end, and no secrets (API keys from sponsors must stay
out of it). Record the Loom early on Sunday, not at 3:50pm.
